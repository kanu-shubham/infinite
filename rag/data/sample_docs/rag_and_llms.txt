Title: Retrieval-Augmented Generation and Large Language Models
Source: rag_survey

Large Language Models (LLMs) are neural networks with billions of parameters trained on massive text corpora using self-supervised objectives like next-token prediction. GPT-4, developed by OpenAI, is an LLM that demonstrates strong reasoning, coding, and creative capabilities. Claude, developed by Anthropic, is a family of LLMs focused on safety and helpfulness, trained with Constitutional AI (a technique that uses self-critique to align model behavior). LLaMA-2, released by Meta AI in 2023, is an open-source family of LLMs ranging from 7 billion to 70 billion parameters, trained on 2 trillion tokens of publicly available data.

Retrieval-Augmented Generation (RAG) was introduced by Lewis et al. in 2020 in the paper "Retrieval-Augmented Generation for Knowledge-Intensive NLP Tasks." RAG addresses a fundamental limitation of LLMs: their knowledge is frozen at training time. RAG augments LLM generation with information retrieved from an external knowledge base at inference time, enabling the model to access up-to-date and domain-specific information without retraining.

The basic RAG pipeline consists of three stages: indexing, retrieval, and generation. In the indexing stage, documents are split into chunks, each chunk is converted to a dense vector using an embedding model, and the vectors are stored in a vector database. At query time, the user's question is embedded using the same embedding model, and the most similar chunks are retrieved using approximate nearest neighbor search. The retrieved chunks are prepended to the LLM's context window as "grounding" before the model generates its answer.

HyDE (Hypothetical Document Embeddings), proposed by Gao et al. in 2022, improves retrieval by generating a hypothetical answer document before retrieval. The intuition is that the embedding of a hypothetical answer document is closer to the embedding of real answer documents than the embedding of the original question, because they share vocabulary and structure. In practice, HyDE has been shown to improve retrieval precision especially for queries with vocabulary mismatch.

Self-RAG (Self-Reflective RAG), introduced by Asai et al. in 2023, trains a language model to decide when to retrieve, evaluate retrieved passages for relevance, and assess whether the generated answer is grounded in the retrieved content. Self-RAG uses special reflection tokens: [Retrieve] signals whether external retrieval is needed, [IsRel] assesses passage relevance, [IsSup] checks if the generated text is supported by the passage, and [IsUse] evaluates overall answer utility. Unlike vanilla RAG, Self-RAG is adaptive — it can answer simple factual questions without retrieval.

RAPTOR (Recursive Abstractive Processing Tree for Organized Retrieval), published by Sarthi et al. at Stanford in 2024, builds a hierarchical tree of document summaries for more comprehensive retrieval. RAPTOR clusters chunks of text using Gaussian Mixture Models, generates abstractive summaries of each cluster using an LLM, and recursively builds summary layers. At retrieval time, RAPTOR searches across all tree levels simultaneously, allowing it to retrieve both specific details and high-level conceptual summaries. RAPTOR significantly outperforms naive RAG on multi-document question answering benchmarks.

Embedding models convert text into dense vectors that capture semantic meaning. The sentence-transformers library provides lightweight models like all-MiniLM-L6-v2 (22M parameters) that produce 384-dimensional vectors with strong semantic similarity properties. OpenAI's text-embedding-3-large produces 3072-dimensional vectors and achieves state-of-the-art performance on the MTEB benchmark. Cohere's Embed v3 model supports matryoshka representation learning, allowing vectors to be truncated without significant quality loss.

Vector databases are optimized for storing and querying high-dimensional vectors using approximate nearest neighbor (ANN) algorithms. FAISS (Facebook AI Similarity Search) provides highly optimized CPU and GPU implementations of ANN search. Pinecone is a managed vector database service with automatic scaling and filtering capabilities. Weaviate is an open-source vector database supporting hybrid search combining dense and sparse retrieval. pgvector is a PostgreSQL extension that adds vector similarity search to a traditional relational database.

Faithfulness is a key metric for evaluating RAG systems. A faithful answer contains only claims that are directly supported by the retrieved context. RAGAS (Retrieval Augmented Generation Assessment) is a framework for automated RAG evaluation that computes faithfulness, answer relevance, context precision, and context recall using LLM-as-judge techniques. Research shows that increasing the number of retrieved documents improves recall but may decrease faithfulness as the LLM is tempted to blend retrieved information with parametric knowledge.
