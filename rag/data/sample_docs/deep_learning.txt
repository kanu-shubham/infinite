Title: Deep Learning and Neural Networks
Source: dl_textbook

Deep learning uses neural networks with many layers to learn hierarchical representations of data. The depth of these networks allows them to automatically extract complex features without manual feature engineering, which is why deep learning has achieved breakthrough results in computer vision, natural language processing, and speech recognition.

A feedforward neural network consists of layers of artificial neurons. Each neuron computes a weighted sum of its inputs, adds a bias, and applies a nonlinear activation function. The activation function introduces nonlinearity, enabling the network to learn complex patterns. Common activation functions include ReLU (Rectified Linear Unit), which outputs max(0, x) and alleviates the vanishing gradient problem; Sigmoid, which squashes values to (0,1) and is used for binary classification output layers; and Softmax, which normalizes a vector to a probability distribution over multiple classes.

Backpropagation is the algorithm for training neural networks. It computes the gradient of the loss function with respect to every parameter by applying the chain rule of calculus backwards through the network. An optimizer then uses these gradients to update parameters to minimize loss. Stochastic Gradient Descent (SGD) updates parameters using the gradient of a random mini-batch of training examples. Adam (Adaptive Moment Estimation), introduced by Kingma and Ba in 2015, adapts the learning rate for each parameter using estimates of first and second moments of the gradients, making it more robust and faster converging than plain SGD.

Convolutional Neural Networks (CNNs) are specialized for grid-structured data like images. A convolutional layer applies a set of learnable filters across the input, producing feature maps that detect patterns regardless of their position in the image (translation equivariance). Pooling layers (max pooling, average pooling) downsample feature maps to reduce spatial dimensions and provide some translation invariance. AlexNet, introduced by Krizhevsky, Sutskever, and Hinton in 2012, won the ImageNet competition with a top-5 error of 15.3%, demonstrating that deep CNNs could dramatically outperform traditional computer vision approaches.

Recurrent Neural Networks (RNNs) process sequential data by maintaining a hidden state that captures information from previous timesteps. Long Short-Term Memory networks (LSTMs), introduced by Hochreiter and Schmidhuber in 1997, use gating mechanisms (input gate, forget gate, output gate) to selectively remember or forget information over long sequences, solving the vanishing gradient problem that plagued vanilla RNNs. Gated Recurrent Units (GRUs) are a simpler alternative to LSTMs with only two gates (reset gate and update gate) and comparable performance.

The Transformer architecture, introduced by Vaswani et al. in "Attention Is All You Need" (2017), replaced recurrence with self-attention mechanisms. Self-attention allows each position in a sequence to attend to all other positions, capturing long-range dependencies efficiently in parallel. Transformers use multi-head attention, which applies attention with multiple learned projections simultaneously, and positional encodings to inject sequence order information. The Transformer has become the dominant architecture for natural language processing tasks and has been adapted for computer vision (Vision Transformers, ViT) and other modalities.

Batch Normalization, introduced by Ioffe and Szegedy in 2015, normalizes the activations within each mini-batch to have zero mean and unit variance, then applies learned scale and shift parameters. This reduces internal covariate shift, allowing much higher learning rates and faster training. Layer Normalization normalizes across the feature dimension rather than the batch dimension, making it more suitable for recurrent networks and transformers where batch sizes may be small.

Transfer Learning leverages knowledge from pre-trained models to improve performance on new tasks with limited data. A model pre-trained on a large dataset (source task) is fine-tuned on a smaller dataset (target task). Fine-tuning adjusts all or some of the pre-trained weights using the target task's labeled data. Feature extraction freezes the pre-trained layers and trains only a new classification head. BERT (Bidirectional Encoder Representations from Transformers), released by Devlin et al. at Google in 2018, pre-trains a Transformer encoder on masked language modeling and next sentence prediction, enabling state-of-the-art transfer learning for NLP tasks.
